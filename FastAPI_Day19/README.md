# Day 19: RESTful FastAPI Architecture

## Overview
This repository contains the implementation for **Day 19: RESTful FastAPI Architecture**. It demonstrates a clean, production-ready RESTful API for **Task Management** using **FastAPI** and **Pydantic**.

## Key Features

- **Strict Schema Validation (HTTP 422)**: Implemented data validation using Pydantic `Field` constraints (e.g., minimum title length, positive integer IDs).
- **Explicit Error Handling**:
  - `HTTP 404 Not Found`: Triggered when querying a non-existent task ID.
  - `HTTP 409 Conflict`: Triggered when attempting to create a task with an existing ID.
  - `HTTP 422 Unprocessable Entity`: Automatically generated by FastAPI when payload validation fails.
- **Refactored In-Memory Data Structure**: Migrated storage logic to a key-value dictionary to guarantee $O(1)$ constant-time lookups.
