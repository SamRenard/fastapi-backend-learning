# Bank Account Management System 🏦

A structured Object-Oriented Programming (OOP) implementation of a bank account system in Python. 

## 📝 Description
This project demonstrates the core principles of OOP by simulating real-world banking operations. It incorporates modern Python practices, including strict type hinting (`-> float`, `: str`), logical error handling, and clean code architecture.

## ✨ Features
- **Deposit Funds:** Securely add positive integer/float amounts to the account.
- **Withdraw Funds:** Conditional withdrawal mechanism that prevents overdrawing or processing negative amounts.
- **Balance Inquiry:** Real-time checking of the current account balance.
- **Exception Handling:** Built-in `ValueError` raises for invalid financial operations to ensure system stability.

## 🛠️ Technologies Used
- **Language:** Python 3.x
- **Paradigm:** Object-Oriented Programming (OOP)
