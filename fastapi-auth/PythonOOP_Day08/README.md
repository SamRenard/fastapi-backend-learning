# 🚀 Python OOP: 3D Vector Implementation

This repository contains a professional implementation of a 3D Vector class in Python, designed as part of my journey to becoming an AI Engineer. 

It heavily focuses on **Object-Oriented Programming (OOP)** principles and Python's **Magic (Dunder) Methods**.

## 🧠 Concepts Demonstrated
- **Dunder Methods:** `__init__`, `__add__`, `__sub__`, `__eq__`, `__len__`, `__repr__`
- **Operator Overloading:** Customizing how standard operators (`+`, `-`, `==`) interact with custom objects.
- **Type Hinting:** Improving code readability and static analysis for modern Python development.
- **Error Handling:** Using `isinstance()` checks to prevent invalid operations.
- **AI/ML Fundamentals:** Implementing mathematical concepts like Euclidean magnitude (`math.sqrt`), which are the foundation of many ML algorithms.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Libraries:** Built-in `math` module
