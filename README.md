   # FastAPI Tasks API 🚀

A high-performance, in-memory RESTful API built with FastAPI. This project demonstrates core FastAPI concepts including Path parameters, Query parameters, and robust data validation using Pydantic.

## Features ✨
* **Complete CRUD Operations:** Create, Read, Update, and Delete tasks.
* **In-Memory Storage:** Fast and lightweight testing environment.
* **Pydantic Validation:** Strict request body validation and automatic error handling.
* **Partial Updates:** Ability to update specific fields of a task without rewriting the whole object.
* **Interactive Docs:** Auto-generated Swagger UI integration.
